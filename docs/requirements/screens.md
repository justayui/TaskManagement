# 画面要件書

## 1. 画面一覧

| 画面 | 内容 |
|---|---|
| ボード一覧画面 | 作成済みボードの一覧表示、新規ボード作成 |
| ボード詳細画面 | リスト・カードのカンバン表示、各種CRUD、ドラッグ&ドロップ操作 |
| カード詳細（モーダル） | カードのタイトル・説明文の編集 |

## 2. 画面遷移図

```mermaid
flowchart TD
    A[ボード一覧画面] -->|ボードを選択| B[ボード詳細画面]
    A -->|新規ボード作成| A
    B -->|一覧に戻る| A
    B -->|カードを選択| C[カード詳細モーダル]
    C -->|閉じる/保存| B
    B -->|リスト作成/編集/削除| B
    B -->|カード作成/削除/D&D| B
```
