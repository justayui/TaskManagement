# TaskManagement 要件定義書

## 1. 概要

Trello風のシンプルなタスク管理Webアプリケーションを開発する。
ボード・リスト・カードの3階層でタスクを管理し、ドラッグ&ドロップでカードを移動できる、必要最小限の機能を備えたアプリとする。

## 2. 目的

- Trelloのような直感的なカンバン方式でタスクを可視化・管理できるようにする
- 学習・個人利用を目的とした、機能を絞ったシンプルな構成とする

## 3. 前提条件

| 項目 | 内容 |
|---|---|
| 想定ユーザー数 | 単一ユーザー（ログイン・認証機能なし） |
| データ保存先 | ブラウザのLocalStorage（サーバー・DBは用意しない） |
| 対応端末 | PCブラウザを想定（スマートフォン対応は対象外） |
| マルチデバイス同期 | 対象外（同一ブラウザ内でのみデータが保持される） |

## 4. 対象範囲（スコープ）

### 対象に含む
- ボード・リスト・カードのCRUD（作成・参照・更新・削除）
- カードのドラッグ&ドロップによるリスト間移動、リスト内並び替え
- リストのドラッグ&ドロップによる並び替え
- ブラウザリロード後もデータが保持されること

### 対象外（今後の拡張候補）
- ユーザー登録・ログイン・複数ユーザーでの共有
- サーバー/データベースへの永続化、複数端末間の同期
- カードへのラベル（色分け）、担当者アサイン、コメント、添付ファイル
- チェックリスト、通知、検索・フィルタ機能
- スマートフォン対応（レスポンシブデザイン）

## 5. 機能要件

### 5.1 ボード管理

| ID | 機能 | 内容 |
|---|---|---|
| F-01 | ボード一覧表示 | 作成済みのボードを一覧表示する |
| F-02 | ボード作成 | ボード名を入力して新規ボードを作成する |
| F-03 | ボード名編集 | 既存ボードの名前を変更する |
| F-04 | ボード削除 | ボードを削除する（配下のリスト・カードも削除される） |

### 5.2 リスト管理

| ID | 機能 | 内容 |
|---|---|---|
| F-05 | リスト表示 | ボード内のリストをカンバン形式（横並び）で表示する |
| F-06 | リスト作成 | リスト名を入力して新規リストを作成する（例: 未着手/進行中/完了） |
| F-07 | リスト名編集 | 既存リストの名前を変更する |
| F-08 | リスト削除 | リストを削除する（配下のカードも削除される） |
| F-09 | リスト並び替え | ドラッグ&ドロップでリストの表示順を変更する |

### 5.3 カード管理

| ID | 機能 | 内容 |
|---|---|---|
| F-10 | カード表示 | リスト内にカード（タイトル）を一覧表示する |
| F-11 | カード作成 | リストにタイトルを入力して新規カードを作成する |
| F-12 | カード詳細編集 | カードをクリックしてタイトル・説明文を編集する |
| F-13 | カード削除 | カードを削除する |
| F-14 | カード移動 | ドラッグ&ドロップでカードを別のリストへ移動する |
| F-15 | カード並び替え | ドラッグ&ドロップで同一リスト内のカード順を変更する |

### 5.4 データ永続化

| ID | 機能 | 内容 |
|---|---|---|
| F-16 | 自動保存 | ボード/リスト/カードの変更内容をLocalStorageへ自動保存する |
| F-17 | データ復元 | ページ読み込み時にLocalStorageからデータを復元して表示する |

## 6. 非機能要件

| 項目 | 内容 |
|---|---|
| 動作環境 | 主要モダンブラウザ（Chrome, Edge等）の最新版 |
| パフォーマンス | 個人利用規模（数ボード・数十カード程度）で操作にストレスがないこと |
| データ消失リスク | LocalStorageのためブラウザキャッシュ削除等でデータが消える可能性がある旨を許容する |

## 7. 技術構成（案）

| 項目 | 内容 |
|---|---|
| フロントエンド | React（想定） |
| バックエンド | なし |
| データ保存 | ブラウザ LocalStorage |
| ホスティング | 未定（静的ホスティングを想定） |

## 8. データ構造（案）

```
Board
├─ id: string
├─ name: string
└─ lists: List[]

List
├─ id: string
├─ name: string
├─ order: number
└─ cards: Card[]

Card
├─ id: string
├─ title: string
├─ description: string
├─ order: number
└─ createdAt: string
```

## 9. 画面一覧

| 画面 | 内容 |
|---|---|
| ボード一覧画面 | 作成済みボードの一覧表示、新規ボード作成 |
| ボード詳細画面 | リスト・カードのカンバン表示、各種CRUD、ドラッグ&ドロップ操作 |
| カード詳細（モーダル） | カードのタイトル・説明文の編集 |

## 10. 今後の拡張候補（参考）

- ユーザー認証・複数ユーザー対応（ボードの共有）
- バックエンド・DB導入によるデータの永続化と複数端末同期
- ラベル、期限日、担当者、チェックリスト、コメント機能
- 検索・フィルタ機能
- スマートフォン対応
